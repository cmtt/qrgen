# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-10-26

### Changed (breaking)
- Running `qrgen` in a terminal with no argument and nothing piped in now prints usage and exits with code 2, instead of silently waiting for typed input. To type or paste input as before (finished with Ctrl-D), run `qrgen -`.
- The default margin (quiet zone) is now 4 modules, as the QR specification requires (was 2). Use `-m 2` for the previous size.
- The mask is chosen automatically, and error correction is raised as far as possible without enlarging the code. Codes for the same input therefore look different from 0.1.0 but decode to the same text.
- A single trailing newline (`\n` or `\r\n`) on stdin is no longer encoded, so `echo foo | qrgen` encodes `foo`. Use `--raw` to keep it.
- In a terminal, codes are painted in pure black and white (two colours from the 256-colour palette), so they read correctly on light and dark themes. In the default (full-size) mode every module is background-coloured spaces, with no glyphs, so it renders exactly in any font. `--small` still uses half-block glyphs: in colour, mixed cells are `▄` with the top module as background, which keeps the error small in terminals that draw glyphs from the font. Piped output is unchanged plain text.
- `--version` reports the crate version.

### Added
- Text can be passed as an argument: `qrgen "https://example.com"`. `-` reads stdin explicitly.
- `--color auto|always|never` (default `auto`: colour only when stdout is a terminal; honours `NO_COLOR`, `CLICOLOR_FORCE` and `TERM=dumb`; stays plain on Windows unless `--color always`).
- `shape-rendering="crispEdges"` in SVG output.
- `-i`/`--invert` to swap dark and light modules, for plain output on dark themes.
- `LICENSE` file, crate metadata, GitHub Actions CI, and a test suite: 30 unit tests (every renderer's output is parsed back and compared module by module across all versions, masks and ECC levels; input trimming; per-mode capacity; argument parsing; README/help consistency) and 16 CLI tests.

### Fixed
- Input that is not valid UTF-8 is encoded in byte mode instead of crashing.
- Input too long for a QR code reports a readable error (exit code 1) instead of panicking, naming the limit for that kind of input (7089 digits, 4296 alphanumeric characters, or 2953 bytes).
- Invalid, negative or out-of-range `--margin` values are rejected with a usage error (exit code 2) instead of panicking or cropping the code.
- `--svg` can no longer be combined with the terminal-only options `--small`, `--invert` and `--color` - previously `--small` was silently ignored.

### Dependencies
- clap 2 → 4. This removes `atty` (RUSTSEC-2021-0145) and the unmaintained `ansi_term`.
- qrcodegen 1.6 → 1.8. SVG output is now generated by qrgen itself.
- Edition 2018 → 2021; minimum supported Rust version 1.85.

## [0.1.0] - 2020-04-29
